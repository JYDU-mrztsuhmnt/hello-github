## 四个入门概念

| 名称 | 可以怎么理解 |
|---|---|
| Repository（仓库） | 项目的文件夹 |
| Commit（提交） | 保存一次修改，并留下说明 |
| Branch（分支） | 单独尝试修改的工作版本 |
| Pull Request（PR） | 请人检查并接受修改的申请 |
